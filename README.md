# Редактор монтажа — Telegram Mini App

Одна статичная страница (`index.html`) без бэкенда для бота автомонтажа Reels. Бот передаёт состояние карточки
монтажа в адресе кнопки (`?s=<base64url JSON>`), приложение показывает его на одном экране и возвращает боту только
изменённые поля через `Telegram.WebApp.sendData`.

Хостится на GitHub Pages из этого репозитория. Открыть `index.html` без параметров — покажется демо-состояние,
кнопка внизу печатает JSON, который ушёл бы боту.

## Что на экране

- клипы и общая длительность, «Понял так» и поле для пожелания;
- музыка: тренд / бесплатная / без музыки, свой трек с кнопкой «Убрать»;
- тренд-звук: имя, темп, динамика, «как монтируют», варианты монтажа, «🔁 Другой звук», ссылка на ролики под звуком;
- стиль, текст на экране, кредиты и цена;
- главная кнопка «🎬 Смонтировать · N кр.», вторая — «Сохранить настройки».

Цвета берутся из темы Telegram (`--tg-theme-*`), запасные значения — для предпросмотра в браузере.

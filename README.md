# Reelseex — Telegram Mini App

Одностраничное приложение без сборки: весь интерфейс бота живёт здесь, бот в чате только принимает клипы/ссылки и
отдаёт результаты. Контракт с API — `docs/api-contract.md` (§2 — ошибки и авторизация, §3 — ручки, §4 — экраны).
Хостится на GitHub Pages (`scripts/deploy_webapp.sh` → https://axiomatic-1.github.io/reelseex-editor/).

## Файлы

| Файл | Что |
|---|---|
| `index.html` | разметка-оболочка (`#view`, таббар, тосты) и стили; подключает `config.js` → `vendor/telegram-web-app.js` → `demo.js` → `app.js` |
| `config.js` | `window.REELSEEX = {api, bot}` — адрес API и username бота |
| `app.js` | приложение: `api()`, маршрутизация, экраны, кнопки Telegram, опросы |
| `demo.js` | моки всех ручек API в памяти — демо-режим |

Сборки нет: правишь файлы, деплоишь скриптом. Внешних зависимостей нет: SDK Mini App лежит локальной копией в
`vendor/telegram-web-app.js` (см. «SDK Telegram» ниже).

## Как подключить API

В `config.js`:
```js
window.REELSEEX = {api: "https://<узел>.<tailnet>.ts.net", bot: "Reelseex_bot"};
```
`api` — адрес без слэша в конце; API должен отвечать origin'у Pages (CORS, `API_ORIGIN`). Каждый запрос уходит
с заголовком `Authorization: tma <Telegram.WebApp.initData>`, тело и ответы — JSON.

В репозитории `config.js` **всегда с пустым `api`** (демо-режим, `tests/test_webapp_spa.py` это проверяет): адрес
подставляет `scripts/deploy_webapp.sh` в копию на Pages — из переменной окружения `API_PUBLIC_URL` или строки
`API_PUBLIC_URL=` в `~/Usd-dash/trendreels/.env`; без адреса скрипт останавливается. `--dry-run` делает всё, кроме
push, и печатает diff. Порядок деплоя целиком — `ops/DEPLOY.md`.

Ошибки (§2): `401` → экран «открой приложение из Telegram»; `402` → экран «не хватает кредитов» с переходом
к пакетам Stars в профиле; `409`/`429`/прочие → тост с `message`; нет сети → тост с «Повторить» (на экранах
загрузки — состояние с кнопкой «Повторить»).

## Демо-режим

Включается, если `config.js` без адреса API **или** страница открыта не из Telegram (нет `initData`; исключение —
страницу открыл клиент Telegram, а `initData` пуст: тогда экран ошибки, см. «SDK Telegram»). Все ручки
отвечают моки из `demo.js`, в сеть ничего не уходит, наверху — пометка «Демо-режим». Так страницу можно пройти
целиком в обычном браузере: пользователь с 15 кредитами (админ), 35 звуков, лента из 7 роликов, радар с 2 авторами,
текущий монтаж с 3 клипами и звуком с вариантами. Действия меняют состояние моков: «Смонтировать» → `queued` →
`running` → `done` за ~4,5 с; «Новый монтаж» — клипы «приходят из чата» сами по одному; «Добавить видео» — выбранные
файлы становятся клипами (длительность 5–12 с, байты никуда не уходят); оплата пакета «проходит» через секунду;
разбор/сценарий появляются в карточке ролика через пару секунд.

Параметры URL для демо: `?onboard=1` — начать с онбординга, `?user=1` — обычный пользователь (без админских
переключателей), `?own=1` — у текущего монтажа свой трек.

Вне Telegram вместо MainButton/SecondaryButton рисуется нижняя панель, вместо BackButton — ссылка «← Назад».

## Экраны (§4)

Таббар: **Монтаж · Звуки · Тренды · Радар · Профиль**. Стартовый экран — `start_param` (`m<id>` монтаж, `s`, `t`,
`r`, `p`, `v<id>` карточка ролика) или `?screen=` в URL (те же коды либо `montage|sounds|trends|radar|profile`);
без параметра — Монтаж, если есть текущий, иначе Тренды. Не онбордился — онбординг: ниша (пресеты + своя) → о себе
(можно пропустить) → площадки → готово (`PATCH /me onboarded`).

- **Монтаж.** Нет текущего — «пришли клипы в чат с ботом», кнопка «Новый монтаж» (`POST /montage`), опрос
  `GET /montage/current` раз в 4 с, пока вкладка открыта. Есть — редактор: клипы (× — `DELETE …/clips/{n}`),
  пожелание (textarea, «Сохранить» → `PATCH wish`, ответ показывает «Понял так»), музыка тренд/бесплатная/без
  (свой трек — строка с «Убрать»), тренд-звук с вариантами, «🔁 Другой звук» (`GET /sounds/ranked?mid=` + «Ещё»),
  стиль, текст на экране, у админа «вшить звук в файл». MainButton «🎬 Смонтировать · N кр.» → `POST go`
  (402 → экран кредитов), SecondaryButton «Отмена» → `POST cancel`. `queued/running` — прогресс с опросом
  `GET /montage/{id}` раз в 3 с; `done` — сводка (длительность, стиль, звук с копированием названия, «как поставить
  звук»), «Другой вариант / Другой звук / Другой трек» по `can.*`, MainButton «Новый монтаж». Внизу — история
  (`GET /montages`), карточка прошлого монтажа открывается отдельно.
  **Загрузка видео из приложения:** «➕ Добавить видео» (пустое состояние и секция «Клипы», пока клипов меньше
  `limits.clips`) → скрытый `<input type="file" accept="video/*,.mp4,.mov" multiple>`; без текущего монтажа сначала
  `POST /montage`, потом файлы по одному `XMLHttpRequest`-ом на `POST /montage/{id}/clips?name=…` (тело — сам файл,
  `Content-Type` — его MIME; XHR ради `upload.onprogress`). Строка прогресса на файл, ответ `MontageOut` заменяет
  текущий монтаж, `warnings` — тостом, `413` — тост с сообщением сервера. Проверки до отправки — по `mo.limits`
  (запас `{clips: 10, total_s: 300, upload_mb: 200}`); на время загрузки «Смонтировать» и «Отмена» неактивны, при обрыве
  связи остаток файлов ждёт «Повторить». Клипы `src: "app"`
  показываются с именем файла. В демо мок `POST /montage/{id}/clips` добавляет клип 5–12 с.
- **Звуки.** Список по 30 с бесконечной подгрузкой (`has_more`), карточка: тренд, чарты, Shorts, «как монтируют»,
  варианты с примерами, примеры роликов, ссылки. MainButton «🎬 Смонтировать под этот звук» → `POST /montage`
  (если нет текущего) + `PATCH {music: "trend", sound_id}` → вкладка Монтаж.
- **Тренды.** Поле «ссылка на ролик или канал» → `POST /link` (ролик → карточка, автор → тост «добавлен в радар»).
  Лента по 5 с «Ещё»; `collecting` → «собираю, загляни позже» (перепроверка раз в 15 с). Карточка ролика:
  «🧠 Разбор · N кр.» (или «бесплатно», если `analyzed`), «✍️ Сценарий · N кр.», «🎬 Смонтировать из него»
  (`POST /montage/from-video/{id}`), открыть ролик; ниже — разбор и сценарии, если уже есть («Смонтировать по
  сценарию» → `POST /montage/from-script/{id}`).
- **Радар.** Список и лимит `max`, добавить по ссылке (`POST /radar`), удалить с подтверждением (`tg.showConfirm`).
- **Профиль.** Кредиты и «⭐ Пополнить» (пакеты `stars_packs` → `POST /pay/invoice` → `tg.openInvoice`, по `paid`
  перечитывается `GET /me`), история списаний (`GET /me/ledger`), ниша (тот же выбор, что в онбординге), о себе,
  площадки, час подборки (7, 8, 9, 10, 12, 15, 18, 20, 22), алерты радара, у админа — «вшивать тренд-звук».

Тема — переменные `--tg-theme-*` (запасные цвета для браузера), `tg.ready/expand`, цвета header/background —
`secondary_bg_color`, haptics на действиях, `BackButton` для вложенных карточек.

## Проверка без Telegram

Открыть `index.html` в браузере (демо-режим) и пройти экраны. Синтаксис: `node --check webapp/app.js webapp/demo.js`.
Статические проверки (структура HTML, порядок скриптов, размер файлов, пути ручек по контракту) —
`tests/test_webapp_spa.py`.

## SDK Telegram

`vendor/telegram-web-app.js` — копия официального `https://telegram.org/js/telegram-web-app.js`. Подключаем её, а не
оригинал: telegram.org из России без VPN не открывается (сам Telegram работает), и без SDK у приложения не было
`initData` — оно молча уходило в демо-режим, пользователь видел «готовый» ненастоящий монтаж и ждал ролик, который
никто не рендерил (2026-11-09). Данные запуска клиент передаёт в `#tgWebAppData=…` адреса страницы, SDK читает их
локально — сервер Telegram для этого не нужен.

Обновить копию (раз в несколько месяцев или когда нужен новый метод SDK):

```sh
curl -sS https://telegram.org/js/telegram-web-app.js -o webapp/vendor/telegram-web-app.js && node --check webapp/vendor/telegram-web-app.js
```

Если страница открыта клиентом Telegram (есть `#tgWebApp…` или мост WebView), а `initData` пуст — так Telegram
открывает Mini App с reply-кнопки клавиатуры (`KeyboardButton.web_app`): в `#hash` только `tgWebAppVersion/Platform/
ThemeParams`, без `tgWebAppData` (iOS 9.6, 2026-11-09). `boot()` показывает экран «Не получил данные Telegram» (открой
кнопкой меню чата или inline-кнопкой; «Техническая информация» — имена параметров запуска) — в демо не уходит
(`tests/test_webapp_spa.py::test_no_silent_demo_when_launched_by_telegram`).
